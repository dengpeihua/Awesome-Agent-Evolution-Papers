# User journeys

1. As a researcher, I want a daily, deduplicated digest of papers about agent
   Agent/LLM self-evolution, self-improving and recursive self-improvement, agent
   memory, and LLM continual training, so that I can keep
   up with the field without repeating searches.
2. As an enterprise WeChat user, I want the digest pushed at a fixed local time,
   so that relevant papers arrive in the group every day.
3. As a repository owner, I want every discovery run archived by date and the
   Awesome-style index refreshed, so that the collection remains browsable and
   can be published on GitHub automatically.
4. As an operator, I want a safe manual run and clear failure reporting, so that
   I can verify configuration before enabling unattended scheduling.
5. As a researcher, I want a changed discovery query to trigger a one-time
   historical rescan against the official arXiv source, so that older relevant
   papers missed by third-party lists are recovered instead of remaining blind spots.
6. As a researcher, I want every public paper list and archive index ordered from
   newest to oldest by publication time, while priority signals remain visible as
   labels, so that important badges never make the chronology confusing.
